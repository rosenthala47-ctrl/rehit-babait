# יומן השכבה 📓

אפליקציה לשכבה: ממלאים כל יום מה היה בכל שיעור, ובסוף היום מקבלים סיכום באחוזים של **כל השכבה ביחד**.

## איך זה עובד
1. **השיעורים** — רשימה של כל השיעורים, עם שם המורה של כל אחד. אפשר להוסיף, לערוך, לסדר ולמחוק שיעורים.
2. **הפרמטרים** — בכל שיעור ממלאים כמה דברים. מגיע עם ארבעה: רמת שיעמום, תמונה מהשיעור, ציטוט, וכמה פעמים אמרו 67. **אפשר להוסיף פרמטרים חדשים בכל רגע** מההגדרות.
3. **היום** — אפשר למלא עד 22:00 (ניתן לשינוי). בשעה הזאת היום נסגר, הסיכום מחושב ונשמר בהיסטוריה, ובחצות מתחיל יום חדש.
4. **הסיכום** — לכל פרמטר, אחוז/מספר לכל שיעור בנפרד ולכל היום, למשל "שיעמום: 47% בלשון של מורה X".

## סוגי פרמטרים
| סוג | מילוי | איך זה מסוכם |
|---|---|---|
| סקאלה | סליידר 0–100 | ממוצע באחוזים |
| מונה | כפתור + | ממוצע הדיווחים (כי כולם סופרים את אותו שיעור) |
| כן/לא | שני כפתורים | אחוז ה"כן" |
| טקסט | תיבת כתיבה | כל הציטוטים נאספים |
| תמונה | מצלמה/גלריה | גלריית תמונות של היום |

## שיתוף לכל השכבה
פעם אחת לוחצים **"צור מרחב שכבה"** בהגדרות ומקבלים קישור. כל מי שנכנס דרך הקישור ממלא לאותו מקום ורואה את אותו סיכום משותף.

- בלי הרשמה ובלי חשבונות.
- האחסון המשותף הוא שירות חינמי בלי מפתח (jsonblob, ובגיבוי kvdb). האפליקציה בודקת לבד מה עובד.
- **מי שיש לו את הקישור יכול לראות ולמלא הכול** — זה לא מוגן בסיסמה. לא להעלות דברים רגישים.

## אם אין חיבור
הכול נשמר קודם במכשיר. מילוי שנעשה בלי רשת נכנס לתור ונשלח אוטומטית כשהחיבור חוזר. יש גם ייצוא/ייבוא גיבוי כקובץ.

## טכני
שלושה קבצים סטטיים, בלי build ובלי תלויות: `index.html`, `styles.css`, `app.js`.
מיזוג נתונים: כל מילוי מזוהה לפי `משתמש:שיעור` ביום, והמיזוג לפי חותמת הזמן האחרונה — כך שמילויים במקביל לא דורסים זה את זה.
תמונות נשמרות כל אחת בנפרד ונטענות רק כשצופים בהן, כדי שהנתונים היומיים יישארו קטנים.
