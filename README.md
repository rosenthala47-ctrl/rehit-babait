# רהיט בבית 🛋️

אתר שעוזר לבחור רהיט חדש לבית — רואים איך הפריט ייראה אצלכם בחדר **עוד לפני שקונים**.

## איך זה עובד
1. **הרהיט** — מצלמים/מעלים תמונה של הפריט (ארון, ספה, שולחן...). האתר מסיר את הרקע אוטומטית.
2. **החדר** — מצלמים/מעלים את המקום שבו רוצים את הפריט.
3. **התוצאה** — גוררים את הרהיט למקום, משנים גודל/סיבוב/צל, ומורידים או משתפים תמונה מוכנה.

## מאפיינים
- ממשק בעברית (RTL), מותאם למובייל, כולל צילום ישיר מהמצלמה.
- הסרת רקע בדפדפן (flood‑fill מהקצוות) + מחק ידני לתיקונים.
- הרכבה עם גרירה, צביטה לשינוי גודל/סיבוב, שקיפות וצל ריאליסטי.
- ייצוא PNG ברזולוציה מלאה + שיתוף דרך Web Share API.
- **כל העיבוד מתבצע במכשיר — התמונות לא נשלחות לשום שרת.** קובץ יחיד, ללא תלויות וללא שלב build.

## הרצה
פותחים את `index.html` בדפדפן, או גולשים לגרסה החיה ב-GitHub Pages.
