# מדריך התקנה — מאפס עד רשימת טלפונים

מדריך למי שלא עבד עם טרמינל. כל שלב אומר בדיוק מה להקליד ומה אמור לקרות.
בסך הכל: 20 דקות, רובן המתנה לגוגל.

---

## שלב 0 · לפתוח טרמינל

**Mac:** לחץ `Cmd` + רווח, הקלד `Terminal`, Enter.
**Windows:** לחץ על תפריט התחל, הקלד `PowerShell`, Enter.

נפתח חלון עם טקסט. שם מקלידים את כל הפקודות במדריך הזה. אחרי כל פקודה —
Enter.

> אם פקודה נכשלת, אל תמשיך לשלב הבא. כמעט כל שגיאה כאן נפתרת בשלב הנוכחי.

## שלב 1 · לוודא שיש פייתון

```bash
python3 --version
```

**אמור להדפיס:** `Python 3.10` או מספר גבוה יותר.

| מה קרה | מה לעשות |
|---|---|
| מספר 3.10+ | מצוין, המשך לשלב 2 |
| `command not found` | הורד מ-[python.org/downloads](https://www.python.org/downloads/) |
| מספר נמוך מ-3.10 | הורד גרסה עדכנית מאותו קישור |

**ב-Windows בהתקנה:** חובה לסמן ☑ **"Add Python to PATH"** במסך הראשון של
המתקין. בלי זה שום פקודה לא תעבוד. אם שכחת — הרץ את המתקין שוב, בחר
`Modify`, וסמן.

ב-Windows הפקודה לפעמים נקראת `python` ולא `python3`. אם `python3` לא עובד,
נסה `python` בכל המדריך.

## שלב 2 · להיכנס לתיקיית הפרויקט

פתחת את `sapar-radar.zip` ששלחתי. נניח שהוא בתיקיית ההורדות:

**ב-Windows:**

אם לא — אתה בתיקייה הלא נכונה. חפש איפה פתחת את ה-zip.

> טריק: אפשר להקליד `cd ` (עם רווח) ואז **לגרור את התיקייה לתוך חלון
> הטרמינל** — הנתיב יודבק לבד.

## שלב 3 · להתקין

```bash
python3 -m pip install -e .
```

לוקח חצי דקה ומדפיס הרבה שורות. **אמור להסתיים ב:**
`Successfully installed sapar-radar-1.0.0`

לבדוק שההתקנה תפסה:

```bash
sapar-radar --version
```

**אמור להדפיס:** `sapar-radar 1.0.0`

<details>
<summary>אם כתוב <code>command not found: sapar-radar</code></summary>

ההתקנה הצליחה אבל המערכת לא מוצאת את הפקודה. פשוט הוסף `python3 -m` לפני
כל פקודה במדריך:

```bash
python3 -m sapar_radar --version
```

(שים לב: `sapar_radar` עם קו תחתון, לא מקף.) זה עובד תמיד.
</details>

## שלב 5 · מפתח Google (החלק היחיד שדורש סבלנות)

הסוכן שואל את גוגל מי המספרות באזור. בשביל זה צריך מפתח.

> **על כסף:** גוגל דורשת כרטיס אשראי כדי להפעיל את השירות, אבל בשימוש
> רגיל כאן אתה כנראה לא תשלם כלום.
>
> הסוכן משתמש ב-SKU אחד — Text Search Pro — שמגיע עם **5,000 קריאות חינם
> בחודש**. סריקה של עיר אחת = 15 קריאות. כלומר בערך **330 סריקות-עיר
> בחודש, בחינם**. מעבר לזה: $32 ל-1,000 קריאות (≈ $0.48 לעיר).
>
> אפשר גם להגדיר תקרת התראה: Billing → Budgets & alerts.

1. היכנס ל־[console.cloud.google.com](https://console.cloud.google.com/) עם
   חשבון הגוגל שלך.
2. למעלה בסרגל, לחץ על בורר הפרויקטים → **New Project** → תן שם
   (למשל `sapar-radar`) → **Create**. חכה שהוא ייווצר ובחר אותו.
3. בתפריט (☰ משמאל למעלה): **Billing** → **Link a billing account** →
   הזן כרטיס אשראי.
4. בתפריט: **APIs & Services** → **Library** → חפש **"Places API (New)"** →
   לחץ עליו → **Enable**.
   ⚠️ **חשוב:** חייב להיות ה-**(New)**. יש גם "Places API" ישן — הוא לא יעבוד.
5. בתפריט: **APIs & Services** → **Credentials** → **+ Create Credentials** →
   **API key**.
6. יופיע חלון עם המפתח. **העתק אותו** — מחרוזת ארוכה שמתחילה ב-`AIza`.

## מכאן — השימוש היומיומי

```bash
# עיר אחרת
sapar-radar run --area "חיפה"

# כמה ערים
sapar-radar run --area "רמת גן" --area "גבעתיים"

# רק המספרות בלי אתר בכלל - הלידים הכי חמים
sapar-radar run --area "נתניה" --min-score 85

# כל הערים שבקובץ ההגדרות (יקר יותר - בדוק שהבנת את העלויות)
sapar-radar run
```

**ריצה שנייה לא תיתן לך את אותן מספרות.** הסוכן זוכר את מי כבר הראה לך
ומחזיר רק חדשים. זה אומר שאפשר להריץ כל בוקר ולקבל רק תוספות.

אחרי שהתקשרת:
```bash
sapar-radar mark +97235551234 contacted
sapar-radar mark +97235551234 not_interested --notes "ביקש לא להתקשר"
sapar-radar stats                    # כמה יש, באיזה סטטוס
sapar-radar export                   # כל מה שנאסף אי־פעם, ל-CSV אחד
```

מי שביקש שלא יפנו אליו — הוסף את המספר לקובץ `config/do_not_contact.txt`,
והוא ייעלם מכל דוח עתידי.

## לשנות את הערים שהוא סורק

פתח את `config/config.yaml`, ומצא:

```yaml
search:
  areas:
    - תל אביב
    - רמת גן
```

מחק ערים, הוסף ערים, שמור. אפשר גם שכונות (`פלורנטין`) או רחובות
(`שדרות ירושלים יפו`) — כל מה שגוגל מבין.

## אם משהו נשבר

הרץ תמיד קודם:

```bash
sapar-radar doctor
```

היא כמעט תמיד תגיד לך מה הבעיה. אם היא אומרת שהכל תקין ועדיין אין תוצאות:

- **"לא נמצאו לידים חדשים"** — סביר שכבר קיבלת אותם בריצה קודמת. בדוק עם
  `sapar-radar stats`, ונסה עיר חדשה.
- **מעט מדי תוצאות** — נסה `--min-score 30` כדי לראות גם מספרות עם אתר.
- **לראות מה בדיוק קורה** — הוסף `-v`:
  `sapar-radar run --area "חיפה" -v`
