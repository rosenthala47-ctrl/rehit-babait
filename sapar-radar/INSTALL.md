## שלב 4.5 · לא רוצה כרטיס אשראי בכלל? — חיפוש אמיתי עם OpenStreetMap

גוגל דורש חשבון חיוב (עם כרטיס אשראי) כדי להפעיל את ה-API שלו, גם
לשימוש חינמי לגמרי. אם אתה מעדיף לא לתת פרטי כרטיס אשראי בכלל, יש
חלופה **חינמית לגמרי, בלי הרשמה, בלי מפתח, בלי כרטיס אשראי**:

```bash
sapar-radar run --osm --area "תל אביב" --limit 10
```

זה משתמש ב-**OpenStreetMap** (מאגר מפות פתוח וחינמי) במקום גוגל.

**החיסרון:** המידע על עסקים קטנים בישראל ב-OpenStreetMap פחות מלא מגוגל —
ימצאו פחות מספרות, ולחלקן יחסר מספר טלפון או כתובת. אם זה מספיק לך —
אפשר לדלג ישר לשלב 8 ולהתעלם משלבים 5-7 (הם רק על גוגל).

אם אתה כן רוצה את הכיסוי המלא של גוגל (הרבה יותר מספרות, מידע מלא יותר),
תמשיך לשלב 5.

## שלב 5 · מפתח Google (החלק היחיד שדורש סבלנות)

הסוכן שואל את גוגל מי המספרות באזור. בשביל זה צריך מפתח.

> **על כסף:** גוגל דורשת כרטיס אשראי כדי להפעיל את השירות, אבל בשימוש
> רגיל כאן אתה כנראה לא תשלם כלום.
>
> הסוכן משתמש ב-SKU אחד — Text Search Pro — שמגיע עם **5,000 קריאות חינם
> בחודש**. סריקה של עיר אחת = 15 קריאות. כלומר בערך **330 סריקות-עיר
> בחודש, בחינם**. מעבר לזה: $32 ל-1,000 קריאות (≈ $0.48 לעיר).
>
> אפשר גם להגדיר תקרת התראה: Billing → Budgets & alerts.

1. היכנס ל־[console.cloud.google.com](https://console.cloud.google.com/) עם
   חשבון הגוגל שלך.
2. למעלה בסרגל, לחץ על בורר הפרויקטים → **New Project** → תן שם
   (למשל `sapar-radar`) → **Create**. חכה שהוא ייווצר ובחר אותו.
3. בתפריט (☰ משמאל למעלה): **Billing** → **Link a billing account** →
   הזן כרטיס אשראי.
4. בתפריט: **APIs & Services** → **Library** → חפש **"Places API (New)"** →
   לחץ עליו → **Enable**.
   ⚠️ **חשוב:** חייב להיות ה-**(New)**. יש גם "Places API" ישן — הוא לא יעבוד.
5. בתפריט: **APIs & Services** → **Credentials** → **+ Create Credentials** →
   **API key**.
6. יופיע חלון עם המפתח. **העתק אותו** — מחרוזת ארוכה שמתחילה ב-`AIza`.

## מכאן — השימוש היומיומי

```bash
# עיר אחרת
sapar-radar run --area "חיפה"

# כמה ערים
sapar-radar run --area "רמת גן" --area "גבעתיים"

# רק המספרות בלי אתר בכלל - הלידים הכי חמים
sapar-radar run --area "נתניה" --min-score 85

# כל הערים שבקובץ ההגדרות (יקר יותר - בדוק שהבנת את העלויות)
sapar-radar run
```

**ריצה שנייה לא תיתן לך את אותן מספרות.** הסוכן זוכר את מי כבר הראה לך
ומחזיר רק חדשים. זה אומר שאפשר להריץ כל בוקר ולקבל רק תוספות.

אחרי שהתקשרת:
```bash
sapar-radar mark +97235551234 contacted
sapar-radar mark +97235551234 not_interested --notes "ביקש לא להתקשר"
sapar-radar stats                    # כמה יש, באיזה סטטוס
sapar-radar export                   # כל מה שנאסף אי־פעם, ל-CSV אחד
```

מי שביקש שלא יפנו אליו — הוסף את המספר לקובץ `config/do_not_contact.txt`,
והוא ייעלם מכל דוח עתידי.

## שלב 9 · לעבוד מהטלפון, כאתר — בלי מחשב ובלי טרמינל

יש גרסת אתר של הסוכן (`streamlit_app.py`) — אותה חיפוש, אותם לידים, אבל
בממשק גרפי בעברית שנפתח בכל דפדפן, כולל בטלפון. אחרי שהאתר עלה פעם אחת,
אפשר לשמור אותו במסך הבית של הטלפון ולהשתמש בו כמו אפליקציה.

**חשוב לדעת:** האתר תמיד עובד מול OpenStreetMap (חינם, בלי מפתח). אם
כבר יש לך מפתח Google — אפשר להוסיף אותו בהגדרות האתר (שלב 3 למטה) והאתר
ישתמש בו אוטומטית ברגע שבוחרים "Google Places" בתפריט.

### 1. פרסם את הקוד ל-GitHub (אם עוד לא עשית)

אם עבדת עד עכשיו רק במחשב שלך, תעלה את הפרויקט ל-GitHub — Streamlit
Community Cloud (השירות שיארח את האתר) צריך לקרוא את הקוד משם:

```bash
cd rehit-babait
git add .
git commit -m "sapar-radar"
git push
```

(אם GitHub מבקש שם משתמש/סיסמה ואתה לא בטוח מה זה — יש לך כנראה כבר
חשבון GitHub מהשלב שבו הורדת את הקוד; אם לא, תצטרך להירשם ב-
[github.com](https://github.com) קודם).

### 2. הירשם ל-Streamlit Community Cloud (חינם)

1. היכנס ל-[share.streamlit.io](https://share.streamlit.io)
2. לחץ **Sign up** / **Continue with GitHub** והתחבר עם חשבון ה-GitHub שלך
3. אשר לאתר גישה לריפוזיטורי שלך (`rehit-babait`)

### 3. פרסם את האתר

1. לחץ **New app** / **Create app**
2. בחר:
   - **Repository:** `rosenthala47-ctrl/rehit-babait`
   - **Branch:** `claude/book-phone-search-bot-7xrbjq` (או `main`, לפי מה
     שאתה עובד עליו)
   - **Main file path:** `sapar-radar/streamlit_app.py`
3. **(אופציונלי, רק אם יש לך מפתח Google):** לפני שלוחצים Deploy, פתח
   **Advanced settings → Secrets** והדבק:
   ```
   GOOGLE_MAPS_API_KEY = "המפתח שלך כאן"
   ```
4. לחץ **Deploy**. חכה דקה-שתיים בזמן שהאתר עולה.

**זהו.** תקבל קישור כמו `https://your-app-name.streamlit.app` — זה האתר
שלך, פתוח לתמיד (חינם), נגיש מכל טלפון או מחשב.

### 4. שמור על מסך הבית בטלפון

**iPhone (Safari):** פתח את הקישור → כפתור שיתוף (הריבוע עם החץ) →
"הוסף למסך הבית".

**Android (Chrome):** פתח את הקישור → שלוש נקודות למעלה → "הוסף למסך
הבית".

מעכשיו יש אייקון שנפתח ישר לאתר, בלי דפדפן נראה לעין — בדיוק כמו אפליקציה.

### מה יש באתר

- בחירת עיר, כמות תוצאות, וציון מינימלי — בלי לגעת בקוד
- כרטיס לכל מספרה עם **כפתור טלפון שחייג ישירות** מהטלפון
- כפתור הורדה ל-CSV
- עדכון סטטוס יצירת קשר (התקשרתי / מעוניין / לא מעוניין) ישירות מהכרטיס
- לשונית "כל הלידים" עם כל מה שנאסף אי־פעם וסטטיסטיקות

**מגבלה:** ב-Streamlit Cloud החינמי, אם האתר לא נפתח כמה ימים הוא נרדם
וההיסטוריה עלולה להימחק באיפוס. לשימוש רציני עם היסטוריה שנשמרת תמיד —

## אם משהו נשבר

הרץ תמיד קודם:

```bash
sapar-radar doctor
```

היא כמעט תמיד תגיד לך מה הבעיה. אם היא אומרת שהכל תקין ועדיין אין תוצאות:

- **"לא נמצאו לידים חדשים"** — סביר שכבר קיבלת אותם בריצה קודמת. בדוק עם
  `sapar-radar stats`, ונסה עיר חדשה.
- **מעט מדי תוצאות** — נסה `--min-score 30` כדי לראות גם מספרות עם אתר.
- **לראות מה בדיוק קורה** — הוסף `-v`:
  `sapar-radar run --area "חיפה" -v`
